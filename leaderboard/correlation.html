Metric Correlations Across Problem Difficulties

About This Visualization

This chart shows the correlation between code correctness and various quality metrics across different problem difficulty levels (Easy, Medium, Hard, and All combined).

Easy - Simple problems
Medium - Moderate complexity
Hard - Complex problems
All - Combined data

Statistical Significance Levels:

● p < 0.001 (***) - Highly significant

■ p < 0.01 (**) - Very significant

▲ p < 0.05 (*) - Significant

✕ Not significant
